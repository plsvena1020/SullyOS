# 透视窗（应用活动感知）

> 设计文档：`docs/superpowers/specs/2026-09-13-perspective-multidevice-design.md`
> 执行计划：`docs/superpowers/plans/2026-09-13-perspective-multidevice-plan.md`

## 这是什么

透视窗允许**被你逐个授权的角色**查看你的应用使用记录：用了哪些应用、
每个应用大概用了多久。角色据此在聊天里表现出连续性
（“你刚才去小红书待了二十分钟，找到有意思的东西了吗”）。

## 能看到什么

- SullyOS 内部打开了哪个虚拟 App、进入/离开时间、停留时长。
- Android 安装版：授权“使用情况访问”后，可见其他 Android 应用的包名与使用时长。
- Windows 安装版：可见前台进程的可执行文件名与使用时长。
- 每台设备独立记录，可在设置里按设备清空。

## 看不到什么

- 消息正文、输入内容、窗口标题、网址、网页标题正文。
- 微信聊天对象、文件名、项目名、屏幕画面、剪贴板、通知内容。
- Web 版看不到浏览器之外的任何真实应用（这是浏览器沙盒限制，不是 bug）。

## 配置步骤

1. 部署 Perspective Worker（见 `worker/perspective/README.md`），拿到 Worker 地址。
2. 设置 → 实时感知 → 透视窗：打开总开关，填写 Worker 地址，保存。
3. 在同一面板输入配对码（Worker 侧 `PV_PAIRING_CODE`），点「配对」。
4. 点「测试连接」确认 `已连接`。
5. 进入某个角色的聊天设置，打开底部的透视窗开关。
   未配对时开关会拒绝打开并提示先配对。

## 数据与隐私

- 数据只进你自己的 Worker + D1，SullyOS 官方不经手。
- 每台设备独立令牌，可单独撤销；每个角色独立只读令牌，关闭授权即吊销。
- 设备令牌只保存在本机安全存储，不进入备份文件。
- 记录默认保留 30 天；设置页可清空本设备记录、清理旧数据、重置本机身份。
- 旧 Supabase 透视窗的数据不会自动导入（旧行没有完整的开始/结束/时长），
  首次启动会自动删除旧端点里 `device_id='default'` 的行并清空旧配置。

## 常见问题

- **角色说没看到记录**：检查总开关、Worker 地址、设备配对、该角色授权四项。
- **查询太频繁**：默认两次查询至少间隔 60 秒，可在面板里把间隔改成 0。
- **换 Worker 地址**：重新配对即可，旧设备令牌在新实例上自然失效。
